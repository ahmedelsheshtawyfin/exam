# Ahmed Finance — Case Lab detail design update

This update aligns the case details modal with the approved reference style:

- Cream/off-white page surface and large title treatment.
- Black `KEY FILES` panel with each resource displayed as a dark file row/card.
- Text-first sections below the files, with orange uppercase section labels and subtle separators.
- Removes the separate `CASE OVERVIEW` card entirely.
- Responsive sizing for desktop and mobile while preserving existing case data/API handling.

Updated files:
- `public/app.js`
- `public/styles.css`

No database schema or API changes are included.
