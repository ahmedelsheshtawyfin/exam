# Badge visual redesign

Updated the public badge page to use the real `public/ae-logo.png` asset and a responsive, print-friendly hexagonal credential design. The badge uses the existing achievement color mapping (red for skill assessments, blue for challenges, charcoal for case studies, and charcoal for courses), with the student name, achievement title, optional score, level, issue date, and badge ID. The existing issuance/database and certificate workflows were not changed as part of this visual-only update.

Deploy the Worker and static assets together so `/ae-logo.png` resolves on the badge page.
